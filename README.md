# CS 565 — Human-Computer Interaction

Graduate coursework for Oregon State University CS 565, Spring 2025.

This is a written-deliverable course rather than a programming one, so the repository holds reports, evaluations, and design artifacts rather than source code. It's kept as a record of the design process the course walks through: research a problem, map the user's journey, evaluate against established heuristics, prototype on paper, test with real users, and revise.

## Weeks

| Week | Deliverable |
|---|---|
| w1 | Course framing and a survey of HCI history |
| w2 | Research-paper reading and a case study on user diversity in technology abandonment |
| w3 | User journey map, built from an analysis of Spotify review data |
| w4 | Design-principles investigation — principles in the wild, and a "wall of worst designs" |
| w5 | Heuristic evaluation using Nielsen's heuristics and inclusivity heuristics, with debrief |
| w6 | Paper prototype, usability test plan, and design revision |
| w7 | Revised paper prototype |
| w8 | Cognitive walkthrough, evaluation forms, and the final prototype |
| w9 | Course reflection |

The Spotify review data used for the week-3 journey map is included as CSV.

*Assigned readings that were published third-party research papers are not redistributed here.*
